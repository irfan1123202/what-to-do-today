# Do Your Work By Me 😎

> An ultra-elegant, kinetic productivity suite with 5 interactive luxury themes, animated micro-interactions, acoustic feedback, and priority tracking.

## ✨ Features

- **5 Interactive Luxury Color Themes**:
  - 👑 **Champagne Gold**: Obsidian & 24k Gold
  - 💎 **Royal Sapphire**: Midnight & Celestial Azure
  - 🌿 **Imperial Emerald**: Deep Forest & Jade
  - 🌸 **Rose Gold**: Velvet Wine & Rose Sheen
  - ⚪ **Frosted Pearl**: Alabaster & Platinum Light
- **Kinetic Micro-Animations**:
  - Interactive custom checkboxes with spring-pop and SVG draw animations
  - Celebratory canvas confetti bursts on completing tasks
  - Ambient floating mesh orbs and dynamic cursor spotlight
  - Fluid real-time progress bar with execution rate badges
- **Executive Task Management**:
  - Classifications: 💼 Executive, 💎 Finance, 👤 Personal, ⚡ Urgent, 🌿 Wellness
  - Priority tiers: Low, Medium, High with glowing indicator dots
  - Deadline tracking: "Due Today", "Due Tomorrow", or "Overdue" badges
  - Live keyword search and multi-criteria sorting
  - Inline editing with keyboard shortcuts (Enter to save, Esc to cancel)
- **Acoustic Feedback**:
  - Synthesized zero-latency Web Audio sound effects with mute toggle
- **Local Persistence**:
  - Automatic saving of tasks and active theme preferences in `localStorage`

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Pure Modern CSS (Glassmorphism, CSS Custom Properties, Keyframe Animations)
- **Audio**: Web Audio API Synthesizer
- **Deployment**: GitHub Pages via GitHub Actions
